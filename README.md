# DR SWIM Masters

Website for DR SWIM Masters – Vladimir Antonijević.

## Pokretanje lokalno

1. Instaliraj Node.js 20+.
2. Otvori ovaj folder u PowerShell-u.
3. Pokreni:

```powershell
npm.cmd install
npm.cmd run dev
```

4. Otvori http://localhost:3000

## Deploy

Repository se može povezati sa Vercel-om i automatski deploy-ovati nakon svakog push-a na `main`.
